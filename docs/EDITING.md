# Как безопасно обновлять сайт «Про Массаж»

## Сейчас: редактирование без программирования

Тексты, контакты и список услуг лежат в корневом файле `content.json`. Основной дизайн находится в `index.html`, а иллюстрация — в `assets/wellness-art.svg`.

1. Откройте [content.json](../content.json) в GitHub.
2. Нажмите карандаш **Edit this file**.
3. Измените значения в кавычках. Не удаляйте кавычки, запятые и фигурные скобки.
4. Для добавления услуги скопируйте один объект из массива `services`, затем измените `code`, `title`, `description`, `note`.
5. Нажмите **Commit changes** в ветку `main`.
6. GitHub Actions проверит структуру данных и опубликует сайт. Если проверка не пройдёт, публикация не состоится.

Цены и продолжительность не добавляйте, пока Павел не подтвердит точные значения. Ссылки Telegram должны вести на `https://t.me/...`; секреты и токены нельзя помещать в `content.json`, HTML или публичный репозиторий.

## Какие поля можно менять

- `brand`, `tagline` — название и подпись бренда.
- `heroTitle`, `heroScript`, `heroDescription`, `heroArtLabel` — первый экран.
- `services` — карточки услуг.
- `bookingTitle`, `bookingDescription` — блок записи.
- `telegram`, `phoneDisplay`, `phoneTel` — контакты.
- `aboutTitle`, `aboutDescription`, `aboutQuote` — философия бренда.
- `contactTitle`, `contactDescription` — заключительный блок.

## Защитные меры

- Сайт выводит содержимое как текст, а не как HTML.
- Перед публикацией JSON проверяется по allowlist полей, длине значений и допустимому формату контактов.
- Не существует публичного API, который мог бы менять сайт без авторизации.
- Любого будущего Telegram-бота следует ограничить Telegram ID Павла, хранить GitHub token только в секретах серверной среды и требовать явного подтверждения перед коммитом.
- Для автоматического управления через бота понадобится отдельная серверная функция и секреты; их пока намеренно не добавляли, чтобы не оставлять незакрытый вход в репозиторий.

## Предпросмотр и откат

После коммита проверьте вкладку **Actions** в репозитории. Если что-то пошло не так, откройте историю файла и восстановите предыдущую версию через новый коммит.
